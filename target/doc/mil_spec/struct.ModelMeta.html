Expand description

Model-level metadata written into ModelDescription and the Function’s opset specialization.

spec_version and opset must match an installed CoreML tooling pair — e.g. (8, "CoreML5"), (9, "CoreML7"), (10, "CoreML9"). The Function block is specialized under the same opset name.
